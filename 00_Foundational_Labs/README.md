## Overview

This directory contains introductory arithmetic and sequential digital design blocks implemented in both **Verilog HDL (IEEE 1364)** and **SystemVerilog (IEEE 1800)** with automated ModelSim testbenches:

```
00_Foundational_Labs/
├── alu4/                      # 4-bit ALU with 5 core operations (Verilog & SV)
├── d_flip_flop/               # Positive edge D Flip-Flop with async reset (Verilog & SV)
├── full_adder_8bit/           # 8-bit ripple carry adder built from 1-bit cells (Verilog & SV)
├── full_adder4/               # 4-bit behavioral full adder
├── adder_dff_top/             # 4-bit adder with registered D Flip-Flop output
└── README.md
```
